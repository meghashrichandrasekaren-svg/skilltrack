# SkillTrack

### Track Your Skills. Showcase Your Growth.

SkillTrack is a Student Career Management System designed to help students manage their academic profile, certificates, and internship experiences in one platform.

## 🚀 Features

- 👨‍🎓 Student Profile Management
- 🏆 Certificate Management
- 🖼️ Certificate Image Upload & Preview
- 💼 Internship Tracking
- 📊 Dashboard with Career Statistics
- ✏️ Edit and Update Records
- 🗑️ Delete Records
- 🔗 Internship Reference Links
- 📱 Responsive User Interface
